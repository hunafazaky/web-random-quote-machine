# Random Quote Machine

Shows a random quote at a click, with a one-click share to X.

![Screenshot](./assets/random-quote-machine-web.png)

**Live demo:** [hunafazaky.github.io/random-quote-machine](https://hunafazaky.github.io/random-quote-machine)

## Features

- Random quote on load and on every "New Quote" click
- One-click share to X, pre-filled with the quote text

## Run Locally

Just open `index.html` in your browser — no install, no build step.
